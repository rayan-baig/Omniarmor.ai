How it works

    {% if kind in ('class', 'school') %}

  1. 1Add your class

    Type each student's first name or nickname, one on each line. No email, no birthdate, no photo.

  2. 2Hand out join codes

    Print one code per student. Each student types theirs once on a school device, and plays short lessons.

  3. 3Watch the class progress

    See each student's lessons and the class total, print certificates, and take the one-page report to the office.

    4. {% else %}

  4. 1Enter a date once

    Each check says what to do and the rule it comes from. Enter when it was last done, or answer yes or no, and OmniArmor counts the days from then on.

  5. 2Get reminded before it's late

    Your team gets an email {{ days[:-1]|join(', ') }} and {{ days[-1] }} day{{ 's' if days[-1] != 1 }} before each deadline, on the day, and each week it stays overdue.

  6. 3Show the record

    Every check's status in one report, with who changed what and when. Print it or download it when an inspector asks.
