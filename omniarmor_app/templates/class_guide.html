Teacher guide

The Classroom track: {{ facts.class_worlds }} worlds and {{ facts.class_lessons }} lessons in all, written for {{ facts.grades }} ({{ facts.ages }}).

How it works

  • Your class runs a pretend business: a lemonade stand called {{ facts.class_business }}. The lessons use it for every example.
  • A lesson is {{ facts.lesson_questions }} questions and takes about {{ facts.lesson_minutes }} minutes. A student needs most of them right to unlock the next lesson. A retry asks the same questions in a new order.
  • No question comes back in a later lesson of the same world, so a world has only as many lessons as it has questions for.
  • The first lesson of each world opens the next world. After the first lesson of every world comes the Class Challenge: {{ facts.track.final_questions }} questions from the whole track. Passing it earns a certificate you can print from the class page.
  • Students missed a question? It comes back in "Practice my mistakes" a day, three days and a week later.

Tips

  • One world a week works well: a lesson or two in class, a short talk using the questions above, and the rest as practice.
  • The class leaderboard starts off. Turn it on from the class page if you like: it shows first names and lessons done, for your class only.
  • Students only pick answers: nothing they type is shown to anyone.
